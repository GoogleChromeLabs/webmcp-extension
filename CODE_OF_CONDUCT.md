# Code of Conduct

This project follows
[Google's Open Source Community Guidelines](https://opensource.google/conduct/).

In short: be respectful, assume good intent, and keep discussions focused on the
work. Harassment of any kind is not tolerated.

## Reporting a problem

If someone is behaving in a way that breaks these guidelines, report it to the
project maintainers by opening an issue, or privately through the
[Google Open Source contact form](https://opensource.google/conduct/) if you
would rather not do so in public.
